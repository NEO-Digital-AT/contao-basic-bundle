# Basic – Dokumentation

Basic ist die gemeinsame Grundlage einer Familie von Contao-Erweiterungen. Es
ergänzt die Backend-Seite *Zugänge und Lizenzen*, auf der die Lizenzschlüssel
der installierten Erweiterungen, eine KI-Verbindung, die Zugänge zu Azure
Translator und DeepL und die Schlüssel fremder Dienste einmal eingetragen
werden.
Allein ergänzt es im Backend nichts; die Erweiterungen, die darauf aufbauen,
fügen der Seite ihre Abschnitte hinzu.
