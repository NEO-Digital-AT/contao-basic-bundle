# Basic – documentation

Basic is the shared foundation of a family of Contao extensions. It adds the
back-end page *Access keys and licences*, on which the licence keys of the
installed extensions, one AI connection, the accesses of Azure Translator and
DeepL and the keys of external services are entered once. On its own it adds nothing to the
back end; the extensions that build on it add their sections to the page.
